I contributed to the Community Terrestrial Systems Model (CTSM), an open-source project used to study how land and climate interact. I added tables of contents to two long user-guide pages so readers could jump straight to the instructions they needed.

The pages cover how to configure the land model and customize its settings. I followed a pattern already used in the guide and kept each list short by linking to the main sections. I checked both generated pages to confirm that the navigation appeared, then opened a pull request for maintainer review.

This project taught me to test documentation from the reader's side. The source change was small, but opening the generated pages gave me evidence that it addressed the original problem. I included those results and the limits of my local build in the pull request so maintainers had a clear starting point for review.
